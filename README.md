# Healthcare Risk Analytics Platform

## Overview
A production-style healthcare analytics platform built using RShiny for real-time healthcare risk assessment and predictive analytics.

## Features
- Dynamic CSV Upload
- Interactive KPI Dashboard
- Random Forest Risk Prediction
- Model Accuracy Analytics
- Confusion Matrix Evaluation
- Downloadable Reports
- Reactive Data Pipelines
- Dockerized Deployment
- CI/CD Workflow Integration

## Technologies Used
- R
- RShiny
- Random Forest
- ggplot2
- Plotly
- Docker
- GitHub Actions
- DevOps

## Future Enhancements
- Kubernetes Deployment
- REST API Integration
- Cloud Deployment
